      入稿チェック

      「ページの編集」に並んでいるページを、印刷所に入稿する前の目線で確認します。

      • 仕上がり線(ここで断裁します)
      • 塗り足しの外端(トンボ付きのとき)
      • 断裁で切り落とされる部分(塗り足し)
      • 安全領域(文字はこの内側に)
      • 指摘した文字
      • 指摘した画像
      • 指摘した図形・場所

      指摘の「場所を見る」を押すと、対象をここで強調して示します。枠をクリックすると、その指摘を選べます。

      処理しています…

      処理中は、このタブを開いたままにしてください(ほかのタブに切り替えると、処理が一時停止します)。

      新しい版があります。

      分割して保存

      いま並んでいる順番(カードの番号)で分割します。複数のファイルは ZIP にまとめて保存します。

      分け方

      「1-3, 4-6, 7-」なら、1〜3、4〜6、7〜最後 の 3 ファイルになります。

      ページ番号を入れる

      いま並んでいる順番で番号を入れます。文字は印刷向けの色(CMYK)で、日本語フォント(BIZ UDPゴシック)を埋め込みます。

      表紙に番号を入れないなら「1」にします。

      印刷所に出すときは、安全領域(仕上がりの端から 3〜5mm)より内側にしてください。

      中央寄せの位置では、中央からのずれになります。

      誤植を直す 試験的

      PDF の中の文字を、同じ字数の別の字に置き換えます。直せるのは、PDF に埋め込まれた同じフォントにその字があり、 字の幅が同じで、フォントが文書の編集を許可している場合だけです。いちばん確実なのは、元の Word などで直して PDF を作り直すことです。

      ファイルの扱いについて

      • ファイルは送信しません。PDF の読み込み・編集・保存は、すべてこの PC のブラウザの中で行います。
      • 外部からプログラムを読み込みません。動作に必要なものは、すべてこのサイトに同梱しています。
      • アクセス解析・追跡をしていません。
      • ブラウザの仕組みで外部通信を禁止しています。 コンテンツ セキュリティ ポリシー(CSP)という仕組みで、このサイトから外部への通信をブラウザ自身に禁止させています。

      一度開くと、必要なファイルがこの PC に保存され、インターネットにつながっていなくても使えます。 Chrome / Edge では「アプリとして使う」でインストールすると、PDF を右クリックして「プログラムから開く」で開けます。

      「誤植を直す」や「ページの中」の文字の書き換えで PC のフォントを使うときは、ブラウザの許可を得てから、フォントをこの PC の中で読むだけです(送信しません)。

      パスワードや編集制限がかかった PDF は扱いません。保護を解除する機能は、意図して用意していません。

      このサイトは GitHub Pages で配信しています。配信元の GitHub は、ページを開いたときの一般的な記録(IP アドレスなど)を持つことがありますが、PDF の中身が送られることはありません。 ソースコードは公開しており、誰でも中身を確かめられます: github.com/kaeauiama/online-pdf-tuner
