# 04. 入稿の最終調整(M7)

状態: 2026-10-07 実装済み。D-033(チェックの追加・指摘のフォーカス表示)、D-034(文字のアウトライン化)、D-035(色の調整)。
閾値は `src/print/thresholds.ts`、変換の基準は `src/print/cmykLut.ts`(自動生成)を正とする。

## 1. 指摘の場所のフォーカス表示(D-033)

指摘が多いと、どの対象のことか分からなくなる。そこで、指摘ごとに「場所」(ページと範囲、説明)を持たせ、
選んだ場所をプレビューで強調する。

- 指摘のカードに「場所を見る(N か所)」。選ぶと「前へ / 次へ」と「3 / 12・2 ページ目・線幅 約 0.04mm」のように示す
- プレビューは、その場所のページに移り、場所以外を暗くし(スポットライト)、枠と説明を添える
- 場所がページの面積の `AUTO_ZOOM_AREA_RATIO`(4%)未満なら、自動で拡大して表示する(「ページ全体を見る」で戻せる)
- プレビューの枠を押すと、その指摘と場所を選ぶ
- 指摘を選んでいる間は、その指摘の枠だけを描く(ほかの指摘の枠は隠す)

場所を持つ指摘: 文字の位置・画像の解像度・埋め込まれていないフォント(その文字)・透明効果・端の色(辺の帯)と、2 の追加のチェックすべて。

## 2. 追加のチェック(D-033)

Acrobat の出力プレビュー・プリフライトや Illustrator のドキュメント情報にある確認のうち、PDF の描画命令から確実に判定できるもの。
構造の解析(`src/print/structure.ts`)で、描画ごとに色・線幅・オーバープリント・文字の大きさを追い、場所つきで記録する。
トンボなど仕上がりの外だけにあるものは対象外(非表示のレイヤーを除く)。

| 理由コード | 重さ | 判定 |
|---|---|---|
| `PRINT_LINE_ZERO_WIDTH` | 要修正 | 線幅 0 の線(機械で描ける最も細い線になり、ほぼ見えない) |
| `PRINT_LINE_TOO_THIN` | 注意 | CTM を反映した線幅が `THIN_LINE_MM` 未満。塗りの細い長方形(表の罫線)も含む |
| `PRINT_FILL_ONLY_LINE` | 注意 | 面積のない形を塗りだけで描いたもの(線の色の設定がなく、印刷されない) |
| `PRINT_WHITE_OVERPRINT` | 要修正 | 白(インキなし)にオーバープリントが設定されている(印刷されずに消える) |
| `PRINT_SMALL_TEXT` | 情報 | 実際に描かれる大きさが `SMALL_TEXT_PT` 未満の文字 |
| `PRINT_RICH_BLACK_TEXT` | 注意 | `RICH_BLACK_TEXT_MAX_PT` 未満の文字が、リッチブラック(K が `RICH_BLACK_MIN_K` 以上で C+M+Y が `RICH_BLACK_MIN_CMY` 以上) |
| `PRINT_INK_OVER_LIMIT` | 注意 | CMYK の色の総インキ量が `INK_LIMIT_PERCENT` を超える(図形・文字。画像は対象外) |
| `PRINT_SPOT_COLOR` | 情報 | 特色(Separation・DeviceN。レジストレーションとプロセス 4 色を除く) |
| `PRINT_REGISTRATION_COLOR` | 注意 | レジストレーション(Separation /All)が仕上がりの内側の絵柄に使われている |
| `PRINT_HIDDEN_LAYER` | 注意 | 既定で非表示のレイヤー(OCG・OCMD)の中の描画 |

## 3. 文字のアウトライン化(D-034)

「入稿用 PDF を作る」の「文字をアウトライン化する」。文字を、埋め込まれたフォントの字形の輪郭(図形)に置き換える。

- 処理は文字の塊(BT 〜 ET)ごと。字形の輪郭はフォーム XObject として 1 度だけ作り、`q 行列 cm /字形 Do Q` で描く
  (塗りの色・透明度などは、その時点の状態を引き継ぐ)。描画モード 1・2(線)はその場でパスを描き、3(見えない文字)は削除する
- 字形の位置は、PDF の字幅(W・Widths)・字間(Tc・Tw)・水平比率(Tz)・TJ の数値・ライズ(Ts)から求める。縦書き(Identity-V)は W2・DW2 による
- フォーム XObject の中の文字も処理する。使わなくなったフォントは資源から外す
- 対応する形式(`src/pdf/glyphs.ts`): Type0(Identity-H / V)+ TrueType または CFF(OpenType・素の CFF。CID の CFF は charset で CID → 字形)、
  単純な TrueType(文字コード → Unicode → cmap)、Type1C(符号化の名前 → 字形の名前。ASCII と /Differences)
- **許諾(ユーザー承認、D-034)**: fsType が「埋め込み不可」と明示されたフォントだけ対象外。埋め込まれている時点で作成ソフトが許諾を確認済みであり、
  アウトライン化は印刷のための処理で文字の編集ではないため、「プレビューと印刷のみ」や、許諾の情報を持たない形式(素の CFF)も対象にする
- 塊の中に、輪郭にできない文字(埋め込みなし・埋め込み不可・未対応の形式・Type3・字形が見つからない・クリップの描画モード 4〜7)があれば、
  その塊は文字のまま残す。直前の文字の状態(フォント・大きさ・字間など)を前に書き足し、見た目を保つ。理由はページごとに表示する
- アウトライン化した文字は、再チェックで文字の位置・大きさの確認の対象にならない。その旨を表示し、元の PDF の結果を参考にしてもらう

## 4. 色の調整(D-035)

「入稿用 PDF を作る」の「色」で選ぶ。既定は「RGB のまま」。

| 選択 | 内容 |
|---|---|
| RGB のまま | 色は変えない(多くの印刷所は RGB を受け付け、印刷所で変換する) |
| 黒い文字と線を K100 にする | 文字・線・図形の無彩色の RGB(R = G = B、許容差 0.02)を K だけにする。ほかの色と画像はそのまま |
| CMYK に変換する | すべての色を DeviceCMYK にする(Japan Color 2011 Coated) |

共通: 「黒い文字と線を K100」と「CMYK に変換」では、`RICH_BLACK_TEXT_MAX_PT` 未満のリッチブラックの文字を K100 にする(文字の後で元の色に戻す)。
白のオーバープリントが見つかったときは「白のオーバープリントを解除する」(既定でオン)を出す。白の間だけ、オーバープリントを切る ExtGState を差し込む。

### CMYK への変換

- **基準**: sRGB → Japan Color 2011 Coated、相対的な色域を維持 + 黒点の補正(Photoshop の既定と同じ考え方)。
  開発時に littleCMS で 33³ 点の変換表を計算して同梱し(`scripts/build-cmyk-lut.mjs`)、実行時は四面体補間する。プロファイル自体は同梱しない(D-029 と同じ扱い)。
  プレビューの「印刷の目安」と同じ基準なので、変換前に仕上がりの目安を確かめられる
- **文字・線・図形・グラデーション**: 無彩色は K だけ(黒い文字・罫線が版ズレでにじまない)。それ以外は変換表どおり
- **画像**: 変換表どおり(写真の黒は 4 色)。RGB の画像は画素を読み出して CMYK にし、可逆圧縮(Flate)で保存する(劣化はないが、ファイルは大きくなる)。
  JPEG はブラウザで読み出す(埋め込みの ICC プロファイルは使わない。PDF の扱いと同じ)。Indexed は色の表だけを変える。SMask は残す
- **特色**: 代替の色(tint transform)を経由して CMYK にする。レジストレーション(トンボ用)はそのまま
- **グラデーション**: 色空間を CMYK にし、関数を CMYK の標本(1 変数は 256 点、2 変数は 33 × 33 点)に置き換える
- **透明グループ**: ページとフォームの /Group /CS を DeviceCMYK にする(ソフトマスクのグループは変えない)
- **模様・Type3 の字形**: 中の描画の色を同じように変換する
- **変換できないもの**: JPEG 2000 などの画像、インライン画像、頂点に色を持つメッシュのグラデーション、読めない関数など。
  そのページは、焼き込み(文字以外を画像に)にしてから変換し直す。理由は表示する
- 処理の順番: 焼き込み(選んだ場合)→ 色の調整 → 文字のアウトライン化 → 塗り足し・トンボ。
  色を先に調整するのは、リッチブラックの文字を K100 にするには文字が文字のままである必要があるため

### やらないこと

- PDF/X の出力(OutputIntent の付与・規格への適合の確認)。D-008 のまま非目標
- 印刷所ごとの別のプロファイル(オンデマンド機など)。必要になったら、変換表を追加する形で検討する
- CMYK の画像の JPEG での保存(画質と大きさの調整が必要。将来の候補)
