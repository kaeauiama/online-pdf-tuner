# 02. 入稿調整(Print Prep)

状態: Check(M2)は 2026-10-06 実装済み。Fix(M3)は草案。差別化の柱(D-005)。

## 背景

Word や PowerPoint で作ったパンフレットを印刷所に入稿するとき、塗り足し・トンボ・フチなしの設定が
Word 上では難しい。そこで、出来上がった PDF を入力にして、ブラウザ上でチェックと修正をできるようにする。

見つけた範囲では、ブラウザで塗り足しやトンボを付けるツールはある(BleedMaker、PDFChamp 等)。
ただし英語圏向けで、日本式トンボ、日本の印刷所ごとのルール、Word 由来の白フチ問題には対応していない。
ここを差別化点とする。

## 用語

- **仕上がりサイズ**(TrimBox): 断裁後のサイズ。例: A4 = 210×297mm
- **塗り足し**(BleedBox): 仕上がりの外側に伸ばす絵柄。一般に各辺 3mm(A4 → 216×303mm)
- **安全領域**: 断裁ズレを考えて、文字などを置かない仕上がり線の内側の帯(印刷所により 3〜5mm)
- **日本式トンボ**: 角トンボ(内トンボ = 仕上がり線、外トンボ = 塗り足し線の二重線)とセンタートンボ

## 印刷所プロファイル

印刷所ごとのルール(塗り足し量、安全領域、推奨解像度、手動チェック項目)は**データとして持つ**。
各プロファイルには出典 URL・原文の引用・確認日を付け、UI には「非公式の目安」と表示する(D-009)。
値の正は `src/print/profiles.ts`。印刷所によらない閾値は `src/print/thresholds.ts`。

## Check(読み取りのみ・M2)

「ページの編集」に並んでいるページを PDF に書き出し、次の 3 つを組み合わせて判定する(`src/print/`)。

- **構造**(`structure.ts`): pdf-lib と自前のコンテンツ解析器(`src/pdf/lexer.ts`)で、寸法・フォント・画像の配置・色・透明・注釈を取り出す
- **文字の位置**(`textBoxes.ts`): pdf.js の getTextContent
- **端の色**(`edges.ts`): pdf.js でページを描画し、仕上がり線の内側と外側の画素を比べる

仕上がり位置は、TrimBox があればそれを使い、なければページの寸法を定形サイズ(またはその塗り足し込みのサイズ)と照合して推定する(`layout.ts`)。

| 理由コード | 重大度 | 内容 |
|---|---|---|
| `PRINT_SIZE_UNKNOWN` | WARN | 仕上がりサイズを判定できない(サイズを選んでもらう) |
| `PRINT_SIZE_MISMATCH` | ERROR | 選んだ仕上がりサイズとページの大きさが合わない |
| `PRINT_MIXED_SIZES` | WARN | ページの大きさがそろっていない(塗り足しの有無の違いも含む) |
| `PRINT_BLEED_TOO_SMALL` | WARN | 塗り足しがプロファイルの値より小さい |
| `PRINT_NO_BLEED` | ERROR | 端まで色があるのに塗り足しがない |
| `PRINT_WHITE_EDGE` | ERROR | 塗り足し込みのサイズだが、塗り足しが白く抜けている |
| `PRINT_TEXT_OUTSIDE_TRIM` | ERROR | 文字が仕上がり線の外にはみ出している |
| `PRINT_TEXT_IN_UNSAFE_AREA` | WARN | 文字が安全領域の外(仕上がり線の近く)にある |
| `PRINT_FONT_NOT_EMBEDDED` | ERROR | 埋め込まれていないフォントがある |
| `PRINT_IMAGE_LOW_DPI` | WARN | 画像の実効解像度がかなり低い |
| `PRINT_IMAGE_BELOW_RECOMMENDED` | INFO | 画像の実効解像度がプロファイルの推奨値より低い |
| `PRINT_PAGE_COUNT_SADDLE` | ERROR | 中綴じでページ数が 4 の倍数でない |
| `PRINT_HAS_ANNOTATIONS` | WARN | 注釈がある(リンクは除く) |
| `PRINT_HAS_FORM_FIELDS` | WARN | 入力欄(フォーム)がある |
| `PRINT_COLOR_DULL` | WARN / INFO | 印刷するとくすみやすい色がある(S2。下記) |
| `PRINT_RGB_CONTENT` | INFO | RGB の色・画像がある |
| `PRINT_TRANSPARENCY` | INFO | 透明効果がある |

暗号化された PDF は読み込みの段階で拒否する(HC-4)ため、チェック項目には含めない。
線幅の検査(`PRINT_THIN_LINE`)は未実装。印刷所の手動チェック項目として表示している。

画像の解像度チェックは、表示サイズが小さい画像と、極端によく圧縮される「平坦な画像」(単色の塗り・なめらかなグラデーション)を対象外にする。
Office は図形の効果にこうした画像を使い、解像度が低くても見た目に影響しないため(D-018)。

## くすみ警告(S2・2026-10-06 実装済み)

出力の PDF は変えない情報表示(D-008 / D-013)。

- **基準**: pdfjs-dist に同梱の `CGATS001Compat-v2-micro.icc`(CC0。米国のオフセット印刷の標準 CGATS TR 001 相当)
- **色域表**: 開発時に `scripts/build-gamut-table.mjs`(littleCMS の WASM 版。開発時のみの依存)で、
  明度・色相ごとの最大彩度の表 `src/print/gamutTable.ts` を生成する。配信物には lcms を含めない
- **判定**: 描画したページの画素(仕上がりの内側)を sRGB → Lab(D50)に変換し、表の最大彩度との差で判定する(`src/print/gamut.ts`)。
  変換式は生成時に lcms の結果と照合している(差は最大 0.03 程度)
- **重大度**: 大きくくすむ色が仕上がり面積の一定割合以上なら WARN、くすみやすい色が少しあれば INFO。閾値は `thresholds.ts`
- **プレビュー**: 「くすみやすい所」(範囲内の色を灰色にし、くすみやすい色だけ元の色で残す)と、
  「印刷の目安」(彩度を明度・色相を保って範囲内に寄せる)を切り替えられる
- **限界**: 日本の印刷(Japan Color)や、オンデマンド機(トナー)の色域とは異なる。画面では「目安」と明示する(U-12)

## Fix(修正・M3・2026-10-06 実装済み)

入稿チェックの結果画面の「入稿用 PDF を作る」から使う(`src/print/fix.ts`)。作った PDF は自動でもう一度チェックし、
結果とプレビュー(トンボ付きなら塗り足しの外端も表示)を確認してから保存する。元のファイルは変更しない。

元のページは Form XObject として埋め込んで描くため、文字や図形はベクターのまま残る。
注釈(コメント・リンク等)は持ち越さない(印刷では使わず、入稿できない印刷所もあるため)。

### 形式

| 形式 | ページの大きさ | ボックス |
|---|---|---|
| 塗り足し込みのサイズ(トンボなし) | 仕上がり + 塗り足し × 2 | TrimBox・BleedBox を設定 |
| トンボ付き(日本式) | さらに外側にトンボ用の余白(`marks.ts` の暫定値、U-6) | 同上。トンボはレジストレーション色(Separation `/All`)で描く |

### 塗り足しの作り方(塗り足しのないページ)

| 方式 | 内容 | 利用者への注意表示 |
|---|---|---|
| 鏡写し(mirror) | 端の帯を、仕上がり線を軸に反転して外側へ描く(辺 4 + 角 4) | なし |
| 拡大(scale) | ページ全体を、塗り足しまで覆う大きさに拡大する | 切れる量(mm) |
| 白いフチを取り除く(region) | 描画した画素から白いフチを除いた中身の範囲を求め(`bounds.ts`)、塗り足しの外端まで広げる。縦横比を保つ(はみ出しは切れる)か、変えてぴったり合わせるかを選ぶ | はみ出して切れる量、または変形の大きさ(%) |
| 付けない(none) | 白いフチのデザイン向け | なし |

- 既定は、端まで色があれば鏡写し、なければ「付けない」
- 「対象ページ」で方式を使うページを絞れる(表紙だけ「1」など)。対象外の塗り足しのないページは「付けない」
- 元から塗り足しのあるページは、仕上がり位置をそろえてそのまま置く(塗り足しが足りなければ注意を表示)
- 単色で塗る方式は、鏡写しで代用できるため実装していない
- ページ内の特定の画像だけを拡大する方式は、未実装(コンテンツストリームの書き換えが必要)

### その他

| 操作 | 内容 |
|---|---|
| 白紙の挿入 | 中綴じでページ数が 4 の倍数でないとき、指摘のボタンから、最後のページ(裏表紙)の前に白紙を足す。編集画面の並びに入るので、元に戻すこともできる |
| 注釈・フォームの平坦化 | 未実装。入稿用 PDF では注釈を持ち越さないことで代える |

### 非対応(理由コードで明示)

| 理由コード | 内容 | 理由 |
|---|---|---|
| `UNSUPPORTED_FONT_EMBED` | 未埋め込みフォントの埋め込み | フォントファイルがブラウザ側にない。元データで埋め込み直す必要がある |
| `UNSUPPORTED_CMYK_CONVERSION` | RGB → CMYK 変換 | 変換先の印刷条件が決まらず、結果も検証できない(D-008、`01-scope.md` 注記 B)。印刷所側の変換に任せる。くすみやすい色は「くすみ警告」(S2)で知らせる |
| `UNSUPPORTED_PDFX_OUTPUT` | PDF/X-1a 準拠の出力 | CMYK 変換と透明の分割統合が前提になるため |
| `UNSUPPORTED_TRANSPARENCY_FLATTEN` | 透明の分割統合 | ページの画像化以外に手段がない(U-4) |
