# 03. ページ内の編集(M6)

状態: 2026-10-06 実装済み(`src/editor/`、`src/app/editorView.ts`)。D-028。同日、操作性の追加(D-030)を実装。

実装で加えたこと: 検索用の見えない文字が重なっている画像は、重なっている文字の内容で「文字の画像「…」」と表示する
(PowerPoint は効果付きの文字を、2×2 画素の色の画像 + 透明マスクとして描き、その上に見えない文字を重ねる)。
q 〜 Q の中に別の要素が入れ子になっている要素は「固定」(移動不可、削除は描画の命令だけ)とする。

## 目的

PDF のページの中にある要素(画像・文字・図形・グループ)を、Photoshop のレイヤーのように重なり順で一覧し、
影やぼかしなどの効果がどの要素に付いているかを分かるようにする。そのうえで、要素の移動・拡大縮小・削除をできるようにする。

## 画面

作業台の 3 つ目のタブ「ページの中」。

- **左**: ページの選択(編集画面の並び順)
- **中央**: ページの大きな表示。選んだ要素の枠(本体は青、関連する効果は紫)。枠の中をドラッグで移動、四隅の取っ手をつまんで拡大縮小
  (反対の角を固定し、縦横比を保つ。効果と見えない文字も同じ割合で変わる)
- **右**: レイヤーパネル。上が手前(最後に描かれたもの)。各行に、種類のアイコン・名前・印(半透明、効果、見えない文字)。
  効果や見えない文字は、関連する本体の下に字下げして表示する
- **下**: 選んだ要素の位置と大きさ(mm)を数値で表示・入力。「効果も一緒に動かす」(既定オン)。重なり順のボタン。文字の要素なら「文字を変える」欄

変更はタブの中の作業用のコピーに対して行い、すぐにプレビューに反映する。「適用」で編集画面の並びに反映する
(元のファイルの新しい版になり、編集画面の「元に戻す」で取り消せる)。タブの中にも、操作ごとの「元に戻す」を持つ。

適用していない変更があるまま、ほかのタブやページへ移ろうとしたときは、アプリ内のダイアログで
「適用して移動」(既定)・「破棄して移動」・「このページに残る」を選んでもらう(Esc で閉じたら残る)。
ブラウザの確認ダイアログ(`confirm`)は、文言が選べず環境によって出ないことがあるため使わない。

## 要素の取り出し(`src/editor/elements.ts`、純粋関数)

コンテンツストリームを解析器(`src/pdf/lexer.ts`)で読み、描画の命令ごとに「何を・どこに・どの状態で」描いたかを集める。

| 種類 | 描画の命令 | 範囲の求め方 |
|---|---|---|
| 画像 | `Do`(Image)、`BI` | 単位正方形を CTM で写した範囲 |
| グループ | `Do`(Form) | フォームの BBox を Matrix と CTM で写した範囲。中身は展開しない |
| 文字 | `Tj` `TJ` `'` `"` | 文字の行列(Tm・Td・TL・Tc・Tw・Tz・Ts)とフォントの字幅から、基準線上の範囲を求め、字の高さを足す |
| 図形 | `f` `S` `B` など | パスの点(`re` `m` `l` `c` `v` `y`)を CTM で写した外接矩形(線は線幅の半分を足す) |
| グラデーション | `sh` | クリップの範囲(なければページ全体) |

同じ「いちばん内側の q 〜 Q」の中にある描画は、1 つの要素にまとめる(Office の出力は、図形や文字の塊ごとに q 〜 Q で囲む)。
要素には、その q 〜 Q の命令の位置(開始と終了)を持たせる。移動・削除はこの範囲に対して行う。
q 〜 Q で囲まれていない描画(ページ直下の描画)は、その描画の命令だけを範囲とし、移動はできない(削除のみ)。

各要素の状態: 塗り・線の不透明度、ソフトマスク、描画モード、文字の描画モード(Tr)。

## 効果と見えない文字の関連づけ(推定)

PDF には「この影はあの図の影」という情報がないため、描画の順番と位置から推定する。

- **効果**: 半透明・ソフトマスク付き・描画モード付きの要素 E のすぐ後(3 要素以内)に、不透明な要素 N があり、
  E の範囲の半分以上が N の範囲と重なる(または N を少し広げた・ずらした範囲に収まる)とき、E を N の効果とみなす
- **見えない文字**: 不透明度 0 か描画モード 3 の文字で、すぐ前の画像と範囲の半分以上が重なるもの(Office が画像にした文字の上に重ねる検索用の文字)

推定は外れることがあるので、画面では「関連(推定)」と表示し、利用者が付け外しできるようにする。

## 編集の書き換え

- **移動・拡大縮小**: 要素の `q` の直後に `cm` を 1 つ差し込む。差し込む行列は、ページ座標での変換 M を、
  その時点の CTM(C)の座標系に直したもの: `C × M × C⁻¹`(PDF の cm は「新しい行列 × 現在の CTM」のため)
- **削除**: 要素の `q` 〜 `Q` を取り除く
- 書き換えは元のコンテンツの命令の位置を基準にまとめて行う(`spliceAll`)。要素の取り出しと同じ解析結果を使うので、位置はずれない

## 重なり順の変更(`src/editor/order.ts`、純粋関数)

「最前面へ」「前面へ」「背面へ」「最背面へ」(Ctrl+Shift+] / Ctrl+] / Ctrl+[ / Ctrl+Shift+[)。

- q 〜 Q はグラフィックス状態を保存・復元するので、同じ親(同じ q 〜 Q の中、またはページ直下)に並ぶ q 〜 Q どうしは、
  間に状態を変える命令がなければ、入れ替えても見た目が変わらない。間に状態を変える命令(色・CTM・q で囲まれていない描画・
  マークの区切りなど)があるところで区切り、区切りの間(一続き)の中でだけ入れ替える。間にあってよいのは `MP` `DP` `BX` `EX` だけ
- 要素の単位は、要素の q 〜 Q を外側へ、直前の BDC / BMC と直後の EMC(タグ付き PDF のマーク。オプショナルコンテンツを含む)、
  およびほかの要素を含まない外側の q 〜 Q(透明度などを外側で設定する書き方)まで広げる
- BT 〜 ET の中の q 〜 Q は対象外(文字の行列は q 〜 Q で保存されないため)
- 本体と、その効果・見えない文字は 1 つのまとまりとして動かす
- 書き換えは、一続きの中の各単位の場所に、新しい順番の要素の単位(移動・削除・文字の書き換えを反映したもの)を入れ直す
- 入れ替えられないときは、ボタンを止め、理由を示す(「前後の要素と描画の設定がつながっているため」など)

## 文字の書き換え(`src/editor/textEdit.ts`)

文字の要素を選ぶと、文字表示の命令(`Tj` `TJ` `'` `"`)1 つ(多くは 1 行)ごとの欄が出る。誤植修正と同じ安全の条件に従う
(D-022 / D-027): フォントの許諾が「編集可」のときだけ、字は埋め込まれたフォントの中から使い、ない字は PC の同じフォントから補う。

- 誤植修正と違い、字数・字幅が変わってもよい。後ろの文字の位置は自動では詰め直されないため、幅が変わるときは
  「約 N% 広く(狭く)なります。重なる(すき間ができる)ことがあります」と示す。選択の枠も、書き出しの位置を固定して幅を変える(目安)
- 変えていない先頭と末尾の字は、字間の調整(`TJ` の数値)も含めて元のまま残す。変えた部分の字間の調整は外れる(示す)
- 書き換えられないフォント(許諾・形式)は、欄を止めて理由を示す。ない字は「PC のフォントで補う」を案内する
- q 〜 Q で囲まれていない(動かせない)文字も書き換えられる
- 画像になった文字(Office の効果付きの文字)は、文字としては変えられないことを示す

## やらないこと(この段階)

- 文字の回り込み・行の詰め直し(PDF には文章の流れの情報がない)。複数の文字表示の命令にまたがる書き換え
- グループ(フォーム XObject)の中の要素の個別の編集
- 回転・変形(移動と縦横比を保った拡大縮小のみ)
- 一続きをまたぐ重なり順の変更(見た目が変わるため)
- 新しい画像や図形の追加(文字は「文字を入れる」で追加できる)

## 理由コード

| 理由コード | 内容 |
|---|---|
| `EDIT_NOT_MOVABLE` | q 〜 Q で囲まれていない描画で、ほかの描画と状態を共有しているため、動かせない(削除はできる) |
| `EDIT_IN_GROUP` | グループの中の要素は個別に編集できない(グループごと動かす) |
| `EDIT_ORDER_LIMIT` | これ以上手前(奥)に移せない、または重なり順を変えられない(前後の要素と描画の設定がつながっている) |
| `TEXT_NOT_EDITABLE` | 書き換えに対応していない書き方で記録された文字 |
| `TEXT_FONT_UNSUPPORTED` | 書き換えに対応していない形式のフォント |
| `TEXT_FONT_LICENSE` | フォントが文書の編集を許可していない(プレビューと印刷のみ・埋め込み不可) |
| `TEXT_FONT_LICENSE_UNKNOWN` | フォントの許諾が読めない(PC の同じフォントで確認できる) |
| `TEXT_GLYPH_MISSING` | 埋め込まれたフォントにない字 |
| `TEXT_LOCAL_FONT_NOT_FOUND` | 足りない字を補う PC のフォントが見つからない |
| `TEXT_LOCAL_FONT_LICENSE` | PC のフォントが編集のための埋め込みを許可していない |
