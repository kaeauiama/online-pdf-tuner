# PDF 作業台(仮称)

ブラウザの中だけで動く PDF ツールです。ファイルはインターネットに送信されません。

- **ページの編集**: 結合・分割・並べ替え・回転・抜き出し。ページ番号・文字入れ(日本語フォント同梱)。画像 ⇔ PDF。誤植の部分修正(試験的)
- **入稿チェック**: 日本の印刷所(東京カラー印刷・キンコーズ・アクセアなど。非公式の目安)に入稿する前に、
  塗り足し・文字の位置・フォントの埋め込み・画像の解像度・印刷でくすみやすい色などを確認
- **入稿用 PDF を作る**: 塗り足しの生成(鏡写し・拡大・白いフチの除去)、日本式トンボ、仕上がり位置(TrimBox)の書き込み、透明効果などの焼き込み
- **オフラインで使える**: 一度開けばインターネットなしで動く。Chrome / Edge ではアプリとしてインストールでき、PDF を「プログラムから開く」で開ける

- **送信しない**: 読み込み・編集・保存は、すべてブラウザの中で行います
- **外部から読み込まない**: 動作に必要なプログラムやデータは、すべてこのサイトに同梱しています
- **追跡しない**: アクセス解析は入れていません
- **ブラウザに禁止させる**: Content Security Policy で、外部への通信をブラウザ自身に禁止させています

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト
npm run test:e2e   # ビルドして E2E テスト(Windows の Edge を使用)
npm run build      # dist/ に静的サイトを出力
```

方針と仕様は [CLAUDE.md](CLAUDE.md) と [docs/](docs/) を参照してください。
